A single funny line, written to make a reader laugh out loud on a first read — an entry for the [One Line, One Laugh](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3) bounty on [make.fun](https://make.fun).

## The line

> My sourdough starter survived the move, the breakup, and a three-day blackout. It is now my emergency contact, and frankly the most reliable relationship I have.

## How it works

`main.py` writes the line to `/output/entry.txt` (161 characters, inside the 200-character cap). Run it with:

```sh
python3 main.py
```
